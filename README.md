# Pizza Sales SQL Analysis

## Project Overview
This project analyzes pizza sales data using SQL to identify sales trends and business insights.

## Tools Used
- MySQL
- SQL

## Key Analysis
- Total orders and revenue
- Most popular pizza sizes
- Top 5 best-selling pizzas
- Sales by pizza category
- Hourly order distribution
- Busiest ordering dates

## Skills Demonstrated
SQL queries, aggregations, joins, grouping, sorting, and data analysis.
